# Contributing

This is a personal professional portfolio. Suggestions, corrections, and reproducible improvements are welcome.

Before contributing:
- Explain the scientific or technical purpose of the change.
- Cite authoritative sources and dataset licences.
- Preserve raw data and document processing steps.
- Use SI units where appropriate and state any exceptions.
- Do not upload confidential, restricted, personal, or unlicensed material.
- Separate observations, calculations, and interpretations.
