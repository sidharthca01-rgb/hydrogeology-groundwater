# Hydrogeology and Groundwater

> Hydrogeological concepts, field-data templates, and groundwater assessment workflows.

## About

This repository is a framework for organizing hydrogeological observations and analyses. It can include well inventories, water-level monitoring, aquifer descriptions, pumping-test calculations, hydrochemical datasets, and groundwater maps.

Clearly distinguish measured, calculated, and interpreted values. Include units, sampling dates, methods, quality-control notes, and data provenance. Do not present screening-level analysis as a substitute for a site-specific professional investigation.

## Scope

- Aquifer types and conceptual models
- Well inventory and water-level monitoring
- Pumping-test data and parameter estimation
- Groundwater flow and recharge concepts
- Hydrochemical facies and plots
- Groundwater vulnerability and resource assessment

## Data and scientific integrity

- Identify the source, author/organization, date, licence, and version of external data.
- Record coordinate reference systems, units, scale, and methods where relevant.
- Do not invent field observations, analytical results, coordinates, or citations.
- Label synthetic/demo data clearly; never present it as field or laboratory data.
- Include uncertainty, assumptions, and limitations in interpretations.
- Respect site access, safety, privacy, and data-sharing restrictions.
